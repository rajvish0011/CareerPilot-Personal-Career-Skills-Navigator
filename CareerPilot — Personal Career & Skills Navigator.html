How does Python handle memory management and what is the difference between shallow copy and deep copy?

Python manages memory via a private heap managed by the Python memory manager. It uses reference counting alongside a generational garbage collector to reclaim cyclic references. • Shallow Copy (`copy.copy()`): Creates a new outer object, but inserts references to the original nested objects. Modifying nested mutable objects affects both. • Deep Copy (`copy.deepcopy()`): Recursively duplicates every object found in the original, ensuring complete independence.

import copy
orig = [[1, 2], [3, 4]]
shallow = copy.copy(orig)
deep = copy.deepcopy(orig)
orig[0][0] = 99
# shallow[0][0] becomes 99, but deep[0][0] remains 1
PYTHON

What are Python Generators and the `yield` statement, and why are they memory efficient?

Generators are functions that return an iterator using the `yield` keyword instead of `return`. Unlike normal functions that compute their entire result and store it in memory, generators yield values on-the-fly one at a time (lazy evaluation), maintaining their execution state between calls.

def fibonacci_gen(limit):
    a, b = 0, 1
    while a < limit:
        yield a
        a, b = b, a + b

for num in fibonacci_gen(100):
    print(num)
